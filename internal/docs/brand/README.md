# Brand Strategy — Working Name Orbis Commerce
Status: draft (for review, not signed off)
Date: 2026-11-03
Baseline: Orbis Commerce PRD v1.4.5 + Phase 2.3 handoff
**Brand status:** placeholder, final name not signed off.

## Positioning
Operationally dependable commerce platform for growing merchants: clear pricing, trustworthy cash/stock state, easy tenant branding, and flexible service modules.

## Design intent
White-forward professional UI, calm blue highlights, compact data tables, accessible mobile task flows; no exaggerated dashboard claims. The storefront builder allows each tenant's own colors, hero/logo, sections, trust indicators, ratings/sold-count toggles and footer branding controls as entitled.

## Voice and trust
Concise Indonesian, clear action errors and sync status; never imply a pending offline transaction is settled. Warn when channel/provider experimental.
